# ADR-002: v1 同步请求内联推理（无任务队列）

- **状态**: accepted
- **日期**: 2026-11-02
- **Change**: alarm-image-verify

## 背景

REQUIREMENT 锁定入图 API 为同步：一次请求等待识别结束并返回类别+置信度。

## 决策

v1 **不引入** Celery/RQ/Kafka 等队列；在请求处理路径内完成：校验 → 落盘 → 推理 → 写库 → 响应。目录扫描协程/线程同样同步跑完一条再记成功。

## 备选

- 异步 task_id + Worker
- 轻量内存队列

## 理由

对齐 AC-1/AC-7；空仓优先闭环；CONTEXT 偏好避免过早引入消息队列。

## 后果

- 高并发时请求线程/协程会被推理占用，需限制并发与上传大小
- 冷启动（模型加载）不计入软目标；进程启动时预加载模型
- v2 若改异步，属新 CHANGE，可保留同步接口作兼容
